# LumOS Theme

A beautiful OpenWrt LuCI theme.

## Compatibility

- OpenWrt 19.07
- OpenWrt 21.02+
- ImmortalWrt

## Installation

### Build from Source

```bash
git clone https://github.com/xiaoqi2020/luci-theme-lumos.git
cd luci-theme-lumos
make
```

### GitHub Actions

Push to GitHub and the workflow will build automatically.
